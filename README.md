# Licdo-Jaime-abogado

Landing page corporativa y responsive para el Licdo. Jaime Gómez Araúz, abogado litigante en Panamá.

## Incluye
- Responsive móvil/tablet/desktop
- SEO técnico básico
- Open Graph
- JSON-LD LegalService
- robots.txt
- sitemap.xml
- llms.txt
- Estructura orientada a conversión
- Áreas de práctica y proceso de atención
